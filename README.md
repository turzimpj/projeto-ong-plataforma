## 📖 Sobre o Projeto

A **Faz Bem** é uma organização comprometida com a transformação social. Por meio da solidariedade, educação e alimentação, nossos projetos atuam diretamente nas necessidades da comunidade, com base em nossos valores de empatia, inclusão e desenvolvimento humano, seguimos construindo um futuro mais justo e solidário.

Este repositório contém o código-fonte do website estático da organização, que apresenta seus projetos e permite o cadastro de novos voluntários e doadores.

---

## ✨ Funcionalidades

* **Página Home:** Apresentação da missão, valores e informações de contato da ONG.
* **Página de Projetos:** Detalhamento dos principais projetos, como:
    * Cozinha Comunitária
    * Reforço Escolar
* **Seção de Ação:** Chamadas para ação (CTAs) claras para voluntariado e doações.
* **Página de Cadastro:** Formulário completo para captação de dados de novos voluntários/doadores.
* **Validação e Máscaras (JS):** O formulário de cadastro utiliza JavaScript para:
    * Aplicar máscaras de input em tempo real para CPF (`123.456.789-00`).
    * Aplicar máscaras de input para CEP (`12345-678`).
    * Aplicar máscaras de input para Telefone (`(11) 98765-4321`).

---

## 💻 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais:

* **HTML5:** Para a estrutura semântica do site.
* **CSS3:** Para estilização (através do arquivo `css/style.css`).
* **JavaScript (ES6+):** Para manipulação do DOM e interatividade no formulário de cadastro (máscaras de input).

## 🔧 Como Executar

Este é um projeto web estático. Não há necessidade de instalação de dependências ou build complexo.

1.  **Clone o Repositório**
    ```bash
    git clone [https://github.com/seu-usuario/faz-bem.git](https://github.com/seu-usuario/faz-bem.git)
    ```

2.  **Acesse a Pasta**
    ```bash
    cd faz-bem
    ```

3.  **Abra no Navegador**
    Basta abrir o arquivo `index.html` diretamente no seu navegador de preferência (Chrome, Firefox, etc.) para visualizar o site.

    > **Alternativa (Servidor Local):** Se preferir, você pode usar uma extensão como o "Live Server" no VS Code para rodar o projeto em um servidor de desenvolvimento local.
